# Robert Lapine Photography

The portfolio website for Robert Lapine Photography, featuring landscape and wildlife work from across the American West.

## Features

- Six curated photography collections
- Onsite full-screen photo viewer with keyboard navigation
- Filterable portfolio archive
- Long-form field stories
- Contact, print, and licensing information
- Responsive layouts and social-sharing metadata
- Flickr integration for Robert's larger archive and original files

## Local development

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm test
```
